# OpenAI o1 预览版发布（2024-09-12）

> **事件类型**：模型发布
> **核心问题**：通过训练阶段与推理阶段增加计算，能否改善模型在复杂任务上的表现？

## 时间线

- **2024-09-12**：OpenAI 发布 o1-preview 和 o1-mini，并称其训练目标包括让模型在回答前花更多时间处理复杂问题。
- **2024-12-05**：OpenAI 发布 o1 system card，补充模型能力、安全评估和限制信息。
- **后续变化**：产品和 API 中可用的模型会退役或迁移。本文讲的是 2024 年的发布，不是当前模型选型指南。

## 核心背景

OpenAI 在发布文章中将 o1 描述为经大规模强化学习训练、能够使用更多推理时计算的模型系列。该方法使推理过程和模型训练成为研究重点之一，但 benchmark 结果只反映特定数据集、提示和评测设置，不代表模型在所有现实任务中都更可靠。

“推理模型”也不意味着模型像人一样思考。理解模型行为时，应结合训练方法、评测设计、系统卡和实际任务测试，不要把产品文案直接当作认知科学结论。

## 学习要点

- **评测要看任务和设置**：采样次数、可用计算、工具和数据集都会影响结果。
- **推理能力有成本**：增加推理计算可能影响延迟与费用，需按具体任务比较收益。
- **能力与可靠性要分开评估**：解题表现提升不等同于事实准确性、安全性或通用可靠性都提升。
- **使用当前服务前查官方文档**：模型名称、接口支持与生命周期会变化。
