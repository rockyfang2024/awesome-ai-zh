# 🧠 深度学习学习路径

> 深度学习是当代 AI（特别是 LLM）的核心技术基础。

## 🎯 必学顺序

1. **神经网络基础**（1-2 天）—— 感知机、激活函数、反向传播
2. **CNN / RNN**（2-3 天）—— 图像和序列数据
3. **Transformer**（1 周）—— 现代 LLM 的核心
4. **训练技巧**（1 周）—— 优化器、正则化、批归一化

按高校课程系统学习：可从 [MIT 6.S191](13-university-open-courses.md) 开始；课程目录页说明先修要求和公开材料范围。
