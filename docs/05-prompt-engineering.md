# 💬 Prompt 工程

> 怎么问 AI 问题，让它给你想要的答案？

## 🎯 必学技巧

1. **清晰指令** —— 不要模糊，明确你想要什么
2. **Few-shot** —— 给几个例子让它学
3. **Chain-of-Thought** —— 让它一步步思考
4. **角色设定** —— 给它一个角色
5. **结构化输出** —— 要求 JSON / 表格 / 列表

## 🛠️ 实战技巧清单

### 基础技巧

| 技巧 | 示例 |
|------|------|
| **明确角色** | "你是一位资深 Python 工程师" |
| **明确任务** | "翻译以下文本为英文" |
| **明确格式** | "用表格输出，包含 X、Y、Z 三列" |
| **明确长度** | "200 字以内" |
| **明确语气** | "用正式 / 幽默 / 简洁的语气" |

### 进阶技巧

| 技巧 | 用途 |
|------|------|
| **Few-shot** | 给 2-3 个例子让模型学格式 |
| **Chain-of-Thought** | "一步步思考" 提升推理能力 |
| **ReAct** | 让模型推理 + 行动 |
| **Self-Consistency** | 多次采样取众数 |
| **Tree-of-Thought** | 多分支探索 |
