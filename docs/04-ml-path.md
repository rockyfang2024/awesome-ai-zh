# 📊 机器学习经典学习路径

> ML 基础是理解深度学习的前提。如果你想做数据科学或算法工程师，这一章必学。

## 🎯 必学顺序

1. **数学基础**（线性代数、概率、微积分）—— 1-2 周
2. **监督学习**（回归、分类）—— 1 周
3. **无监督学习**（聚类、降维）—— 3 天
4. **模型评估**（交叉验证、metrics）—— 3 天
5. **特征工程** —— 1 周

## 📂 完整资源列表（附录）

### 算法分类

#### 监督学习

- 线性回归 / 逻辑回归
- 决策树 / 随机森林
- SVM
- KNN
- 朴素贝叶斯

- K-Means
- DBSCAN

#### 模型评估

- 准确率 / 精确率 / 召回率 / F1
- ROC-AUC
- 交叉验证
- 偏差-方差权衡
