# 🤖 LLM / 大模型学习路径

> LLM 是当前 AI 革命的核心。学完这一章你能理解 ChatGPT、Claude、DeepSeek 等大模型是怎么工作的。

## 🎯 必学顺序

1. **Transformer 原理**（1 周）—— 现代 LLM 全部基于此
2. **主流模型对比**（3 天）—— GPT / Claude / Gemini / DeepSeek / Qwen
3. **API 使用**（2 天）—— OpenAI / Anthropic SDK
4. **Prompt 工程**（3 天）—— 让模型输出你想要的结果
5. **RAG & Agent**（1 周）—— 让模型"做事"
