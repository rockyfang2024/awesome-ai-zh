# 🎓 高校 AI 公开课程与学习资料

整理高校公开的 AI、机器学习和深度学习课程。优先链接学校、课程团队或学校图书馆的原始页面。

**“公开课程”不一定等于完整自学课**：有些页面只公开课程大纲或讲义，视频、作业或平台访问可能需要注册或校内账号。每项资源都注明可见范围；开课时间、材料和访问政策以原页面为准。
